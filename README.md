**THE SOFTWARE:**

Simply compile the main program with `make`

This includes the main server (`inventory-server`) which runs on port 9142, an ncurses interface (`inventory-tui`), as well as an HTML file which can be used to perform basic device addition/removal. I use an nginx instance with a proxy_pass.

**THE PROCESS:**

The "version 1.0" code was completed in three hours, using the Luna model that duck.ai defaulted to, just barely fitting within one provided session/content window.
